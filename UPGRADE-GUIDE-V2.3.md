# Cinematic V2.3 upgrade

No new Supabase SQL is required.

Changes:
- live project previews now fill the entire media frame instead of rendering as a scaled-down mini desktop
- project preview area is larger on desktop
- Data Intelligence capability chips are aligned in a 4-column grid (2-column on small screens)
- process step numbering no longer visually collides (no 0101/0202 effect)
- YouTube playlists render as compact side-by-side cards on desktop, two-column on tablet, one-column on mobile
- Showcase section is shorter, darker and more cinematic
- outcome labels use a controlled grid so text cannot run into adjacent labels
- external profile links are normalized so `www.linkedin.com/...` opens as HTTPS instead of a localhost route
