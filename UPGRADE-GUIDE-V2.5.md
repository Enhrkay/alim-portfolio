# Cinematic V2.5

This build focuses on the two visual issues identified during local testing:

- Live project previews are deliberately zoomed so the landing page occupies the browser stage rather than appearing as a small page inside a large frame.
- The Showcase / learning area is forced into the cinematic dark treatment, with three compact side-by-side YouTube media cards on desktop and reduced vertical height.

No Supabase migration is required. Keep the existing `.env.local` file and database.
